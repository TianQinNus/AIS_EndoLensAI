# EndoLens AI E2：Mac 准备、Windows CUDA 训练、Mac 分析

## 1. 本轮实验路线

E2 不再是从 E1 权重继续 20 轮。先重新训练三个开发模型，使用固定的内部验证集选方案；确定方案后，从对应初始化重新训练全部 1450 对，再测试。

| 阶段 | 模型 | 更新数据 | 选择依据 |
|---|---|---|---|
| E2-A | 当前原始 U-Net，随机初始化 | 1160 对开发训练数据 | 290 对验证数据 Dice |
| E2-B | ResNet34-U-Net，随机初始化 | 同上 | 同上 |
| E2-C | 与 B 完全相同的 ResNet34-U-Net，ImageNet 预训练编码器 | 同上 | 同上 |
| 可选增强对照 | 较好方案加适度旋转、亮度和对比度增强 | 同上 | 同上 |
| E2-Final | 验证选定方案，从初始参数重新训练 | 全部 1450 对 | 事先固定训练轮数，随后测原来的 798 条目 |

B/C 的结构、解码器初始化方式、批量、损失、优化器、种子和训练预算相同，只改变编码器的初始权重。A 与 B 的比较涉及整体网络变体，不能将差异全部归因于单一编码器因素。原 E1 留作历史基线，不覆盖。

开发训练使用 seed42、352×352 输入、AdamW 初始 lr=1e-4/weight_decay=1e-4、BCE+逐图 soft Dice（smooth=1）、物理 batch2/累积4、有效 batch8、100 轮。前5轮线性 warmup，随后 cosine 衰减到初始学习率的0.1。训练默认 FP16 AMP，损失与验证使用 FP32。验证每轮恢复原尺寸，再按阈值0.5计算逐图二值 Dice/IoU；不做逐图 min-max。

ResNet34 编码器保留 torchvision 的 BatchNorm，并更新参数和运行统计；解码器使用 GroupNorm(8)，减小其对小物理 batch 的依赖。梯度累积不会扩大 BatchNorm 的统计批量。原始 U-Net 没有归一化层。两种网络都是已有思路的任务实现，不声称原创架构。

开发阶段保存验证 Dice 最高的 best.pth，平分时保留更早轮次。最终训练使用选定轮数，保留原100轮学习率曲线的时间轴，不把 cosine 压缩到较短轮数。最终从头训练，而不是继续开发 best 检查点，也不是继续 E1。

## 4. Windows 环境

建议独立环境，保留 E1 环境。下列命令在 Windows 的 Anaconda Prompt 或已支持 conda 的 VSCode 终端运行：

```bat
conda create -n endolens-e2-win python=3.11 -y
conda activate endolens-e2-win
cd /d "F:\Semester1\ISY5002-PracticeModule\Polyp-PVT\Polyp-PVT"
python -m pip install --upgrade pip
python -m pip install -r e2_windows/requirements-windows.txt --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r e2_windows/requirements-common.txt
python -c "import sys,torch,torchvision; print(sys.executable); print(torch.__version__,torchvision.__version__); print(torch.cuda.is_available())"
```

固定 PyTorch 2.9.1 / torchvision0.24.1 的 CUDA12.8 wheel，与之前实际成功执行 CUDA 的版本路线相符。NumPy1.26.4/Pillow10.2.0。无需 segmentation_models_pytorch；无需为了运行预编译 wheel 单独安装 CUDA Toolkit。驱动须支持该 CUDA wheel。若环境安装或驱动出错，设备探测会终止，不转CPU。

CMD 的 `cd /d` 不适用于 PowerShell。PowerShell 进入目录用 `Set-Location "F:\...\Polyp-PVT"`。后续 Python 命令两种终端均可使用。

## 5. GPU 检查、单元测试和 smoke

```bat
python e2_windows/check_device.py --device cuda --output runs/e2_gpu_device_proof.json
python e2_windows/test_e2.py
python e2_windows/run_e2.py download-weights
python e2_windows/run_e2.py train --experiment pretrained --device cuda --smoke --output runs/e2_smoke_C_seed42
```

也可以在已激活 conda 环境的终端执行：

```bat
cmd /c e2_windows\01_check_and_smoke.cmd
```

设备探测使用实际352输入和ResNet34-U-Net，在 CUDA 上完成前向、BCE+Dice反向及AdamW参数更新，确认输出在CUDA且参数确实改变。下载阶段验证官方权重文件名对应的 SHA 前缀，正式训练记录完整SHA256。

单元测试故意使用CPU和合成数据，只检查功能，不是正式实验。smoke只用8个开发训练样本、5个内部验证样本、1轮，标记GPU_SMOKE，不接触测试集。分数很低或0不能据此判断最终质量。它不能参与 select，也不能通过 evaluate 测试正式798条目。

**正式训练的成功设备标志：**

```text
TRAIN DEVICE=cuda:0; GPU=NVIDIA GeForce RTX 5060 Laptop GPU; ... AMP=True
```

每轮还会记录 `last_device_proof`：model/images/masks/logits都应为cuda:0，forward_dtype一般float16、loss_dtype为float32。`environment.gpu`、CUDA版本、能力、nvidia-smi信息、显存峰值与AMP跳过更新次数会保存。没有CUDA时直接报 `E2 TRAINING REQUIRES CUDA. No CPU fallback.`

## 6. 正式开发实验（先完成这里再回来分析）

三个实验串行执行，避免同时争抢8GB显存：

```bat
python e2_windows/run_e2.py train --experiment original --device cuda --output runs/e2_dev_A_original_seed42
python e2_windows/run_e2.py train --experiment random --device cuda --output runs/e2_dev_B_resnet_random_seed42
python e2_windows/run_e2.py train --experiment pretrained --device cuda --output runs/e2_dev_C_resnet_pretrained_seed42
```

或执行 `cmd /c e2_windows\02_train_development.cmd`，任一步失败就停止后续步骤。

默认workers2。如果Windows多进程加载有问题，可使用 `--workers 0`；这是CPU读取数据的线程策略，不会把模型训练改成CPU。GPU使用率随解码、验证和写检查点波动是正常的。任务管理器的3D曲线不能单独判断训练设备；可在另一个终端运行 `nvidia-smi` 查看Python进程与显存。

默认batch2/accumulation4/AMP是保守起点，不保证每台8GB电脑都不会OOM。如果OOM，启动**新目录**并在所有配对模型中一致使用 `--batch-size 1 --accumulation 8`。不能用改变批量的命令续训原run。物理batch更改会影响BatchNorm统计，须在报告记录。

代码打印每轮训练与验证秒数及粗略剩余时间。建议以实际前3–5轮计时估算，不用E1单轮时间直接预测。

可选后续增强实验（先观察A/B/C，再决定是否执行）：

```bat
python e2_windows/run_e2.py train --experiment pretrained --augmentation strong --device cuda --output runs/e2_dev_C_strong_seed42
```

strong增加±15度旋转、0.85–1.15亮度/对比度变化。几何操作对图像和mask同步应用，mask最近邻插值。它属于单独增强消融；不要把不同增强的结果称为仅比较预训练。本包第一轮不加入结构损失、注意力或融合。

## 7. 中断与续训

Ctrl+C会结束当前训练，并保留最近完整轮的last.pth。关闭/kill终端一般也会终止进程，但可能来不及更新状态；以磁盘上的完整检查点为准，推荐Ctrl+C。

```bat
python e2_windows/run_e2.py resume --run-dir runs/e2_dev_C_resnet_pretrained_seed42 --device cuda
```

续训使用原配置，不追加epochs、不换batch/损失/学习率。代码、清单签名、设备类型、GPU型号和依赖版本须一致。保留last.pth以及对应best.pth和可能生成的best_backup.pth；不要在训练时编辑Python源码。GPU OOM或CUDA错误不会静默退回CPU。

每个开发run至少包含：

如果只看表格，可以不传last.pth，但建议保留整个run以便追溯。不要只传一个pth，丢弃日志和清单。

## 9. 选择方案并完成最终训练

此步在开发结果分析之后进行。可以Mac上运行select，再把生成的JSON/CSV传Windows；也可直接Windows执行。select只读验证结果，绝不读测试分数。若预训练未胜出，代码会如实选验证较好方案，不强行选择C。

```bat
python e2_windows/run_e2.py select --runs runs/e2_dev_A_original_seed42 runs/e2_dev_B_resnet_random_seed42 runs/e2_dev_C_resnet_pretrained_seed42 --output runs/e2_selection_seed42.json
python e2_windows/run_e2.py train-final --recipe runs/e2_selection_seed42.json --device cuda --output runs/e2_final_seed42
```

如果分析后增加增强实验，将其run加入--runs列表，并使用新的selection输出文件名。所有候选必须属于同一内部划分和seed。

最终训练从初始参数重新开始，使用全部1450对，不用内部验证集做后续选模。选定模型及best_epoch变成提前固定的最终训练预算。代码不会自动测试多个检查点再选最好分数。

Mac使用已有且通过本包CPU测试的 `polyp-pvt-mac` 环境（PyTorch2.2.2/torchvision0.17.2/NumPy1.26.4/Pillow10.2.0）即可执行下面命令。使用一个环境，避免conda和`.venv`叠加。若该环境没有torchvision，须安装与torch对应的版本。依赖版本与训练端不同会记录在评估信息中，不保证跨后端二值掩膜逐像素完全一致。

```bash
conda activate polyp-pvt-mac
cd "/Users/yucheng/Desktop/NUS-ISS/ISY5002-Practice Module/Polyp-PVT"
python e2_windows/run_e2.py evaluate \
  --project "/Users/yucheng/Desktop/NUS-ISS/ISY5002-Practice Module/Polyp-PVT" \
  --run-dir runs/e2_final_seed42 \
  --e0-run runs/e0_20261004_221345_872444 \
  --e1-evaluation runs/e1_unet_cuda_seed42/evaluation_cpu_20261005_023119_069660 \
  --device cpu --threads 4
```

生成五个子集与ALL汇总，同时与E0和E1比较。ALL按798条目加权，而非平均五个子集均值。CUDA/Mac CPU之间的速度不能直接比较；比较耗时须用同一机器、后端、线程、精度和输入设置。模型前向计时与含读图/保存的分析循环分别记录。

## 11. 本机验证范围和代码来源

本包在Mac实际完成：

- 数据文件审计、E0测试清单一致性与E1训练内容一致性检查。
- 固定1160/290划分及完全相同RGB图像不跨内部划分。
- 原始U-Net及ResNet34-U-Net的352×352输出形状检查。
- 10项CPU功能/集成测试，包括掩膜对齐、指标边界规则、梯度累积尾批次、初始化加载逻辑、断点续训一致性和CPU训练禁止。
- 实际CLI在无CUDA的Mac拒绝train，未创建训练run。

**尚未在用户Windows/RTX5060上运行。** 官方ImageNet权重下载、实际CUDA AMP兼容性、显存和训练速度需先运行GPU probe与smoke验证。本机初始化加载测试使用合成权重，仅核验结构和加载逻辑，不声称已验证真实预训练权重或取得E2实验结果。

主要来源：

- ResNet： https://arxiv.org/abs/1512.03385
- U-Net： https://arxiv.org/abs/1505.04597
- Torchvision ResNet34与ImageNet权重： https://docs.pytorch.org/vision/0.24/models/generated/torchvision.models.resnet34.html
- PyTorch2.9.1/torchvision0.24.1 CUDA12.8安装对应关系： https://pytorch.org/get-started/previous-versions/
- PyTorch混合精度： https://docs.pytorch.org/docs/stable/amp.html

ResNet34来自torchvision。本包的解码器采用双3×3卷积、GroupNorm、bilinear上采样和多层特征拼接，是明确记录的U-Net变体实现，与SMP默认解码器不完全相同。原始U-Net及E0指标辅助代码来自本项目已验证的E1包。
