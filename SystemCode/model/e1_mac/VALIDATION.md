## 五项自动检查

`python e1_mac/test_e1.py` 全部通过：

1. U-Net 输出形状、损失反向传播、有限梯度、AdamW 更新，以及安全检查点往返加载。
2. BCE+Dice 在 2+2+1 的不完整累积组中，按实际样本数加权后与直接完整 batch 梯度一致（浮点误差容限内）。
3. 图像/标签同步翻转保持逐像素对齐，seed/epoch/sample 相同的增强一致。
4. E0 的双方空掩膜、单方空掩膜和无交集指标规则一致。
5. 实际训练引擎在合成小数据上进行 2 轮训练：第一轮 checkpoint 保存后模拟中断，再恢复；与连续训练的最终模型参数逐元素相同。包含不足完整累积组的末尾样本。

## 真实数据端到端 smoke

最终代码在 CPU 运行：

```bash
python e1_mac/run_e1.py train --project '/path/to/Polyp-PVT' \
  --e0-run '/path/to/runs/e0_20261004_221345_872444' \
  --device cpu --smoke
```

- 标准 base_channels=64，参数数 31,031,745，输入 352×352。
- 物理 batch=2、累积=4；8 张真实训练图，1 轮、1 次 optimizer 更新。
- 执行模型训练、完整优化器 checkpoint 保存、最终权重保存、加载最终权重，并对 5 个来源各 1 张图评估。
- 成功状态 COMPLETED、run_kind=SMOKE、completed_epochs=1、test_processed_count=5。
- 全部 5 份 NPZ 均为 float32 原图大小；概率有限并在 [0,1]。
- PNG 掩膜与 probability>=0.5 一致。
- 从保存结果独立重算逐图 Dice、MAE；与 CSV 一致。
- ALL 均值与逐图平均一致，E1−E0 指标差值正确。

smoke 使用随机初始化模型且只有一次权重更新，当前五张图的阈值预测均为背景，Dice=0。这只说明管线输出可验证，不能评价正式 E1 的学习能力；不据此改变测试阈值或调整模型。也测试过 64×64/base=8 的快速 smoke，该结果同样不用于正式实验报告。
