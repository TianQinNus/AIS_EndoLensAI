# Experiment progress reports

The five EndoLens AI Word reports document E0–E4. They include completed experiments, validation/test comparisons, limitations and follow-up plans. E4 is the latest model progress report; E5 fusion and video application work remain planned.

Historical local paths in these reports do not define the current repository structure. Use the root README and `SystemCode/model/docs/TEAM_GUIDE.md` for installation. These reports are not the final course submission. The unrelated HDB template PDFs are archived in `Miscellaneous/template_reference/ProjectReport/`.
